# F.O.R.M. — Precision in the O-Stage

Use F.O.R.M. when "what do I want" isn't specific enough.

| Letter | What to define |
|---|---|
| **F — Function** | The deliverable type ("a LinkedIn article", "a product image", "a video script") |
| **O — Output Dimensions** | Size, count, format constraints ("800 words, 5 sections", "--ar 2:3 --s 850") |
| **R — Reference Anchors** | Source documents, style guides, brand assets ("grounded in A1 Brand Voice") |
| **M — Mandatory Elements** | Non-negotiable must-haves ("must include: one data point per section") |

## Example

```
[F] A LinkedIn thought leadership article. Not "some content" — name the type.

[O] 800 words. 5 sections. Markdown. Short paragraphs.

[R] A1 Brand Voice. A3 Customer Persona. Industry report.

[M] Provocative opening. One data point per section. Call to reflection.
```

Without F.O.R.M., the AI guesses at format, length, and style. With F.O.R.M., it knows exactly what success looks like.
