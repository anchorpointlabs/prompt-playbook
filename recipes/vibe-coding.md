# Vibe-Coding an App

Build a working app by describing it in plain English. Works in Google AI Studio (Build) and Gemini.

## The Template

```
[C] You are an app builder. Build exactly what I describe.

[O] App: [one core function — e.g. "a product description generator: one input, one button, one output"]
Vibe: [how it should feel — e.g. "retro, like a 1980s arcade machine"]
Style: use the style from my attached screenshots.

[R] Build the minimum viable product first. Nothing else. Wait for me to test it before adding features.

[E] One feature at a time. If an error appears, give me the fix.
```

## The Three-Part Objective

| Part | Question | Example |
|------|----------|---------|
| Function | What does it do? | "Note-taking app" |
| Vibe | How should it feel? | "Minimalist and calm" |
| Style | What does it look like? | Attached screenshots |

## The Iteration Loop

1. Test the MVP.
2. Add one feature.
3. Test again.
4. If it breaks: paste the error back, say "fix this."

## Why It Works

- **C:** one builder persona, no ambiguity about what "you" are
- **O:** one core function — scope discipline prevents breakage
- **R:** MVP first — the build order is explicit
- **E:** one-feature increments — every step is verifiable
