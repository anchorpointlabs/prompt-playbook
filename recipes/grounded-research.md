# Grounded Research

Research that answers only from your sources — never the open web. Built for Notebook LM, works with any grounding tool.

## The Setup

1. Create a notebook and add sources: upload files, paste links (YouTube videos auto-pull transcripts), add from Drive, or paste text.
2. For serious topics: verify sources first, import only what you trust. For casual topics: use the built-in research tool — approve the good results, deny the rest.

## The Template

```
[C] You are my research assistant, grounded ONLY in this notebook's sources.

[O] Answer: [question]. Format: short answer, then a breakdown. Cite the source for every claim.

[R] Pull from the notebook sources only. If the sources don't cover it, say so — do not reach for the web.

[E] Every claim traces back to a source I can click. No web results. No general-knowledge padding.
```

## What to Ask It

- "How do I get started?" — it knows the topic from your sources
- "Rank all five marketing channels from best to worst" — from your own data
- "Turn this into a slide deck / infographic / report" — Studio assets, grounded in your sources

## Why It Works

- **C:** the notebook IS the context — grounding is the whole game
- **O:** the citation requirement makes every answer checkable
- **R:** explicit "sources only" routing kills hallucinated web content
- **E:** the "say so if it's not covered" gate catches gaps
