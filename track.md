# T.R.A.C.K. — Control in the R-Stage

Use T.R.A.C.K. when you want to control *how* the AI thinks, not just *what* it produces.

| Letter | What it does |
|---|---|
| **T — Technique** | Choose: zero-shot, few-shot, chain-of-thought, skeleton-of-thought |
| **R — Reasoning Chain** | Lay out the step-by-step logic explicitly |
| **A — Abstraction First** | State the higher principle or goal before the task |
| **C — Constraint Acknowledgment** | Restate active boundaries so the AI keeps them in mind |
| **K — Knowledge Injection** | Inject domain facts or data before the AI starts writing |

## Example

```
[T] Skeleton-of-thought.
[R] Step 1: outline. Step 2: expand each section. Step 3: compress to spec.
[A] This is a persuasion task — make the reader feel smarter.
[C] 800 words maximum. One data point per section.
[K] Extract 3 stats from the attached report before drafting.
```

This is not "think about it." This is "here is exactly how to think about it."
